# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-01-25

### Added
- Initial DDD Python template with FastAPI
- Domain-driven architecture with clear layer separation
- User entity and email value object examples
- Basic repository pattern implementation
- FastAPI application with health endpoint
- Comprehensive development environment with devbox
- Testing setup with pytest and coverage
- Code quality tools (ruff, mypy, lefthook)
- Docker and docker-compose configuration
- Workspace directory structure for developer artifacts
- Development container support (.devcontainer)
- Comprehensive documentation (STYLE_GUIDE.md, CONTRIBUTING.md)
- Versioning system with changelog management
- GitHub CODEOWNERS for automated review assignment
